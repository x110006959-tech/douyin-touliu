# AI 评价恢复与完整校验（2026-09-05）

- 问题：已有定性评价恢复会按整段匹配删掉相邻数值；直接删除行业基准词可能留下原来的虚构数字，先撤回建议又可能掩盖其中另一种违规。
- 根因：文本恢复、业务校验与建议投影的顺序没有明确；原不确定性正则还会跨分句替后面的肯定判断放行。
- 修正：只撤回定性评价词；行业阈值和操作条件不自动改写。复用原完整解析器先校验后撤回实验/动作，再次校验返回对象；不确定性限定分句，主结论同步门禁。
- 经验：恢复成功必须证明未改变事实、未掩盖其他错误、未产生未经验证的建议，不能只测试违禁词消失。新增 API 16、LLM 5、Web 2 项回归，最终全仓 653 项与 24/24 离线评测通过，未部署或运行真实模型。
- 完整验收和运行态边界见 `docs/DIAGNOSIS_COMPARISON_RECOVERY_ACCEPTANCE.md`。
