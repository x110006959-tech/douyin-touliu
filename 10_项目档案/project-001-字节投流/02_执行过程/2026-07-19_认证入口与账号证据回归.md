# 2026-07-19 认证入口与账号证据回归

## 结论

- 公开注册和邮箱验证能力没有移除，只从登录页暂时隐藏；管理员发放账号密码的运营方式不等同于服务端强制邀请制。
- 服务端账号自动匹配要求可信 HTTPS 页面、白名单精确路径、声明 URL 参数与检测账号 ID 完全一致。
- 同名、缺少来源、伪造来源和非可信页面都不会自动确认；跨账号 ID 继续拒绝入库。

## 修复

- 修复服务端向共享账号证据工具传参时未将 `accountMatchEvidence` 映射为 `evidence` 的问题。
- 更新 API 回归夹具，区分可信自动匹配、伪造证据待人工确认和跨账号拒绝。
- 移除任务读取中未使用的历史分析与审计预加载，减少串行决策事务工作量。
