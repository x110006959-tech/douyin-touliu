# 2026-07-20 持久化输入边界与认证入口澄清

## 目标

- 明确公开注册与邮箱验证只是前端暂时隐藏，管理员发放账号密码；不移除后端注册、邮件确认/重发和验证页，也不改为服务端邀请制。
- 完成对抗性审查剩余的自由文本、审计元数据和内部派生 JSON 持久化边界收口。

## 实施

- 外部自由文本和 JSON 在写库前拒绝敏感认证形态；覆盖工作区、账号、项目、任务、注册名、手工复核、确认备注、配对标签、心跳错误和审计详情。
- 已清洗快照、规则引擎和 AI 的派生 JSON 再次脱敏后保存，避免 `[REDACTED]` 占位被误判为真实凭证。
- 审计请求元数据只保存截断脱敏后的 `User-Agent`。
- 工作区、系统健康接口拆到独立路由，保持 API 行为和权限不变。
