# V0.2.1 Staging Acceptance

## Extension 制品

- ZIP 名称、manifest、`build-metadata.json`、API `/version`、Web 和 Side Panel 的版本及短 SHA 一致。
- ZIP 中不存在 `injected.js`、`web_accessible_resources`、fetch/XHR 补丁或网络响应采集消息。
- 权限仅包含 `activeTab`、`storage`、`sidePanel` 和明确站点/API 白名单。

## 真实页面

1. 用户手动打开有权访问的目标页面，并手动将关键站点加入 Chrome Memory Saver 例外列表。
2. 验证普通 DOM、真实表格、Canvas、虚拟列表和局部渲染页面的适配器、覆盖率和 PARTIAL 标记。
3. 在标签可见时确认 MetricPulse 最多每 5 秒一条，RealtimeSignal 本地 P95 小于 5 秒。
4. 手动隐藏标签、重载页面并在 `chrome://discards` 丢弃标签，确认实时信号停止并显示页面非活跃；不得自动刷新、导航或保活。
5. 修改测试页面字段名或页面结构，确认产生 MetricDriftEvent；未经人工确认不得自动映射模糊 ROI。
6. 人工确认别名后，仅恢复依赖该指标的动作资格，不得解除主体或来源可信度全局阻断。

## 决策与并发

- 正式建议生成 P95 小于 2 秒，不含人工响应时间。
- 同项目 50 个并发决策只产生一批建议，不突破小时配额，短事务 P95 小于 150ms。
- 预算、暂停和 ROI 目标建议 60-90 秒过期；素材/人群/直播承接 5 分钟；SOP/口碑/服务费用 30 分钟。
- AI 解释不可用时显示确定性模板，正式 decision-engine 继续工作。

## 永久红线

- 零自动点击、零自动改预算、零自动暂停、零自动创建计划、零自动提交表单。
- `mark-manual-executed` 只记录用户已在平台手动完成的操作。
