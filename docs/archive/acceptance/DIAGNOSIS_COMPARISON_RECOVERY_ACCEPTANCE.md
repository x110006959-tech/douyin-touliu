## 实际行为

1. 保留已有的一次模型修复及定向修复提示。第二次响应仍含无依据的定性评价时，只撤回相应评价词，保留主体、数值、单位、相邻事实和证据引用。例如 `成交金额 100.50 元，成交表现良好` 改为 `成交金额 100.50 元，成交表现暂不能判断优劣`。
2. 行业阈值和数值基准不能通过删词变成合格结果；实验步骤、完成/止损条件、候选动作和顶层缺口中的违规评价也不自动改写。模型修复后仍违规则失败关闭。
3. 领域 Skill 和最终综合均复用原完整解析与验证。在撤回本次实验/候选动作之前，先校验修改文案后的完整对象，避免删除建议时掩盖其非法证据、自行计算或其他违规；撤回后再次验证。假设、主标签及所有剩余结果仍受既有契约约束，不生成模板实验或平台动作。
4. 恢复回调抛错或恢复结果再次校验失败时，仍返回失败；已识别的安全错误保留具体类别，未知异常不暴露原始文本。全过程不增加第三次模型请求，Token 用量仍累计两个响应。
5. 核心结论同步覆盖无确定性流量/承接/商品异常时的肯定漏斗判断。否定和不确定语义限定在当前分句，前一句 `暂不能判断优劣` 不会让下一句 `存在明显流失` 逃过检查；`无法判断是否存在流失` 保持合法。
6. Web 对直接或嵌套的 `DIAGNOSIS_BENCHMARK_UNSUPPORTED` 展示具体业务说明：当前证据不能支持该评价或阈值、自动纠正仍不合格、本次未生成建议且采集数据保留，不暴露内部路径或仅要求盲目重跑。
