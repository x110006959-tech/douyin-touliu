# Roadmap

## V0.2.0：固定页面巡检与建议治理（本地完成）

- 用户主动开启的固定目标页面串行巡检。
- 采集批次、路线心跳、完整性和数据新鲜度判断。
- 缺失、过期和连续失败的降级及强动作阻断。
- 建议过期、同类替代、冷却、频率限制和只读预演。
- 业务健康中心、AI 解释熔断和 Extension `0.2.0` 发布包。
- 下一阶段在 staging 用真实页面校准路线 URL、字段别名、指标单位和时间窗口。

## V0.1.3：服务器 staging 部署

- 输出服务器 staging 部署方案。
- 让 V0.1.2 可以在腾讯云 Ubuntu 22.04 Docker 环境中通过 Docker Compose 跑起来。
- 正式域名为 `www.pxxis.cn`，V0.1.3 暂不切换正式流量，先使用服务器 IP 测试。
- PostgreSQL 不暴露公网。
- 不改业务功能。

## V0.1.4：真实页面字段校准

- 使用真实巨量本地推 / 本地生活 / 服务商页面进行字段校准。
- 校准字段来源、字段别名、指标单位、时间窗口和页面模板差异。
- 将低置信或未知字段继续保留在人工复核层。

## V0.1.5：插件上传真实快照到服务器

- 让 Chrome 插件把用户授权采集的真实快照上传到服务器 staging。
- 校验服务器 API 鉴权、脱敏、白名单和错误处理。
- 验证真实快照到数据复核表、决策建议、人工复盘的完整链路。

## V0.2.1：实时性、采集安全与发布一致性（本地实现完成）

- 生产 Extension 移除网络响应拦截，使用页面适配器和 CaptureMeta。
- MetricPulse、SSE、RealtimeSignal 和 Chrome Side Panel 双速链路。
- 按动作证据资格、字段漂移事件和人工别名热校准。
- 任务级并发门禁、Gate/Quota、动态建议有效期和 AI provider/model 熔断。
- 统一版本源、BuildMetadata、正式 migration、ZIP SHA256 与 CI 发布门禁。
- 下一阶段在 staging 验证真实页面覆盖率、P95 延迟、浏览器标签生命周期和 Extension 审核。

## V0.3：团队协作和多项目管理增强

- 增强团队协作、角色权限和多项目管理。
- 增强审计日志、审批流、复盘沉淀和项目级统计。
- 支持更完整的服务商工作台流程。
