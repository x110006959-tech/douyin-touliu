# Roadmap

## V0.1.3：服务器 staging 部署

- 输出服务器 staging 部署方案。
- 让 V0.1.2 可以在腾讯云 Ubuntu 22.04 Docker 环境中通过 Docker Compose 跑起来。
- 正式域名为 `www.pxxis.cn`，V0.1.3 暂不切换正式流量，先使用服务器 IP 测试。
- PostgreSQL 不暴露公网。
- 不改业务功能。

## V0.1.4：真实页面字段校准

- 使用真实巨量本地推 / 本地生活 / 服务商页面进行字段校准。
- 校准字段来源、字段别名、指标单位、时间窗口和页面模板差异。
- 将低置信或未知字段继续保留在人工复核层。

## V0.1.5：插件上传真实快照到服务器

- 让 Chrome 插件把用户授权采集的真实快照上传到服务器 staging。
- 校验服务器 API 鉴权、脱敏、白名单和错误处理。
- 验证真实快照到数据复核表、决策建议、人工复盘的完整链路。

## V0.2：页面模板和指标口径增强

- 增强页面模板识别。
- 增强 `MetricKey`、指标别名、单位换算和置信度策略。
- 提升 unknown 字段进入人工复核层后的处理体验。
- 增强不同本地生活投放场景下的诊断规则。

## V0.3：团队协作和多项目管理增强

- 增强团队协作、角色权限和多项目管理。
- 增强审计日志、审批流、复盘沉淀和项目级统计。
- 支持更完整的服务商工作台流程。
